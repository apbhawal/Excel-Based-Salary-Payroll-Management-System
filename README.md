# 💰 Salary Payroll Management System
> **Personal Skill Development Project | Microsoft Excel | Payroll Management & Reporting**

An Excel-based **Salary Payroll Management System** developed to organize employee attendance, calculate monthly salaries, manage allowances and deductions, and prepare individual employee salary slips through formula-driven worksheets.

---

## 📌 About the Project

This is a **personal skill development project** created to strengthen my practical Excel skills through hands-on experience in payroll management, attendance tracking, financial data handling, and structured reporting.

The project focuses on developing an organized payroll workbook that connects employee attendance records with salary calculations and individual payslip preparation.

Using Excel formulas and cross-sheet references, the workbook provides a structured approach to managing monthly payroll activities and reducing repetitive manual calculations.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Organize employee attendance records.
- Track daily attendance and monthly working days.
- Calculate salary based on employee attendance.
- Manage different salary components and allowances.
- Calculate overtime payments and salary deductions.
- Determine gross salary and net payable salary.
- Prepare structured employee-wise salary slips.
- Improve payroll reporting and data organization.

## 🔄 Payroll Processing Workflow

The workbook follows a structured payroll workflow:

1. **Month & Year Selection** – Set the payroll period.
2. **Attendance Tracking** – Record daily employee attendance.
3. **Salary Calculation** – Calculate attendance-based salary, allowances, and overtime.
4. **Deduction Calculation** – Calculate applicable PF and ESI deductions according to the configured workbook assumptions.
5. **Net Salary Calculation** – Determine the final payable salary.
6. **Payslip Preparation** – Generate individual employee salary statements.

## 🧮 Excel Formulas & Functions Used

This project applies various Excel functions to support payroll calculations and reporting.

| Excel Function | Application |
|---|---|
| `SUM()` | Salary components and deductions calculation |
| `COUNT()` | Counting total working days |
| `COUNTIF()` | Counting attendance categories |
| `IF()` | Conditional salary and deduction calculations |
| `VLOOKUP()` | Retrieving employee salary information |
| `MATCH()` | Identifying salary component columns |
| `DATEVALUE()` | Converting date values |
| `EOMONTH()` | Determining the end of the payroll month |
| `TEXT()` | Formatting dates and weekdays |
| `TODAY()` | Displaying the current salary slip date |
